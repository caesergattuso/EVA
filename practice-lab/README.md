# 新手练习区

这里是给新人做训练的区域，目标是让参与者逐步熟悉 GitHub 协作流程。

## 推荐顺序

1. `level-00-repo-tour/`：先认识仓库结构和入口
2. `level-01-first-edit/`：完成第一次文件修改
3. `level-02-branch-and-pr/`：练习分支、提交和 PR
4. `level-03-review-and-fix/`：练习根据评审继续修正内容

## 你会练到什么

- 找到正确的修改文件
- 新建分支
- 提交改动
- 发起 PR
- 根据 review 继续修改

## 设计原则

- 每一关尽量只练一个关键动作
- 允许出错，重点是掌握流程
- 练习内容不要影响 `real-work/`

## 适合谁

- 第一次参与团队仓库的人
- 想熟悉 GitHub 基础协作的人
- 需要做 onboarding 演练的团队
