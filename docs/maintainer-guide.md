# 维护者指南

这个仓库的重点不是“堆很多内容”，而是“让不同熟练度的人都能快速找到入口”。

## 维护者的主要职责

- 保持首页入口清楚
- 保持练习区和真实任务区边界明确
- 保持任务模板和说明文字统一
- 保持新人能在 5 分钟内找到第一步该做什么

## 如何新增真实任务

1. 用 `.github/ISSUE_TEMPLATE/real-task.yml` 创建 issue。
2. 复制 `real-work/templates/task-template.md`。
3. 放到 `real-work/backlog/`，命名为 `RW-XXX-short-title.md`。
4. 写清目标、交付物、完成标准、风险和负责人。

## 如何新增练习任务

1. 复制 `practice-lab/templates/exercise-template.md`。
2. 放到对应等级目录。
3. 保证这次练习只聚焦一个核心动作。
4. 最好给出明确的目标文件和完成标志。

## 如何判断仓库结构是否健康

- 新人知道自己先去哪里开始
- 真实任务不会和练习内容混在一起
- reviewer 能快速判断任务状态
- 任务完成后能顺利归档
- 文档术语统一，不会一会儿叫 PR、一会儿叫合并申请

## 建议定期检查的内容

- 首页入口是否还准确
- 模板字段是否还够用
- 练习任务是否过大或过旧
- 安全提报说明是否仍然有效
- 是否仍然统一使用 UTF-8 文档编码
