# 工作流说明

这个仓库有两条主流程：真实任务流和新手练习流。

## 真实任务流

建议按下面顺序推进：

1. 用 `Real Work Task` 模板创建 issue，或从 `real-work/backlog/` 认领任务。
2. 在任务文件中写清负责人、目标、交付物和完成标准。
3. 新建任务分支进行修改。
4. 提交 PR，并在描述中写清改动和验证方式。
5. 进入评审，按反馈继续修正。
6. 通过后把任务归档到 `real-work/done/`。

## 新手练习流

建议按下面顺序推进：

1. 从 `practice-lab/README.md` 选择当前关卡。
2. 新建练习分支。
3. 按关卡要求修改指定文件。
4. 提交 PR。
5. 根据 review 做至少一轮修正。
6. 完成后进入下一关。

## Reviewer 重点看什么

### 真实任务

- 目标是否清楚
- 完成标准是否可检查
- 改动是否和任务一致
- 验证方式是否可信

### 新手练习

- 是否理解了本关的核心动作
- 是否按要求修改了指定文件
- PR 描述是否能说清自己做了什么
- 收到反馈后是否能继续修正

## 维护者建议

- 真实任务必须有编号和完成标准
- 练习任务要小、清楚、可重复
- 每个练习最好只训练一个核心动作
- 真正要交付的内容不要放进 `practice-lab/`
