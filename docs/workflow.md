# Workflow

## 真实任务流

建议按下面的顺序推进：

1. 使用 `Real Work Task` 模板创建 issue。
2. 在 `real-work/backlog/` 建立或认领对应任务文件。
3. 开分支处理任务。
4. 提交 PR，进入评审。
5. 通过评审后，把任务归档到 `real-work/done/`。

## 新手练习流

建议按下面的顺序推进：

1. 从 `practice-lab/README.md` 选择当前等级。
2. 新建练习分支。
3. 按关卡说明修改指定文件。
4. 提交 PR。
5. 根据 review 继续修正。

## 维护者建议

- 真实任务要有编号和完成标准。
- 练习任务要小、清晰、可重复。
- 每个练习最好只训练一个关键动作。
- 真正要交付的内容不要放到 `practice-lab/` 中。
