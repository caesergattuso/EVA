# 新人从这里开始

如果你第一次进入这个仓库，建议按下面顺序操作。

## 第一步：先理解仓库分区

- `practice-lab/`：练习区，适合先熟悉 GitHub 操作
- `real-work/`：真实任务区，适合已经了解流程后参与

## 第二步：看规则

先阅读下面两个文件：

- `README.md`
- `CONTRIBUTING.md`

看完后，你应该能回答：

- 我现在该从哪个目录开始
- 我需要开什么分支
- 我要通过什么方式提交改动

## 第三步：从练习区开始

推荐顺序：

1. `level-00-repo-tour`
2. `level-01-first-edit`
3. `level-02-branch-and-pr`
4. `level-03-review-and-fix`

## 第四步：提 PR

提交 PR 时，请至少写清：

- 这次属于哪一关或哪个任务
- 你改了什么
- 你怎么确认自己完成了
- 希望 reviewer 看什么

## 第五步：根据评审继续修改

第一次收到 review 很正常，不代表做错了。对新人来说，最重要的是：

- 能看懂反馈
- 能继续修改
- 能在 PR 中说明自己改了什么
